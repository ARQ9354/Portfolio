# Portfolio — Jordan Blake

A modern, animated developer portfolio built with React, Vite, Tailwind CSS, and Framer Motion.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Customize

Edit `src/data/portfolio.ts` to update your name, bio, projects, experience, skills, and social links.

## Build

```bash
npm run build
npm run preview
```

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Framer Motion
- lucide-react + custom brand icons
