

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173


## Build

```bash
npm run build
npm run preview
```

## Deploy (Render)

Build command: `npm install && npm run build`  
Start command: `npm start`  

The included `server.js` binds to `0.0.0.0:$PORT` and serves the built `dist/` folder.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Framer Motion
- lucide-react + custom brand icons
